# Trailblaze Scout

Scout finds and introduces the right alumni and connections from your Trailblaze network.

This Cursor plugin connects to the remote Trailblaze Scout MCP server at `https://mcp.trailblaze.so/mcp`.

**The MCP server is not live yet.** Installation and sign-in will not work until it is.

## Install in Cursor

The plugin is not listed in the Cursor Marketplace yet. To try it locally:

1. Copy this repository to `~/.cursor/plugins/local/trailblaze-scout`.
2. In Cursor, run **Developer: Reload Window**.
3. Open **Customize** and confirm Trailblaze Scout is loaded. Local plugin imports must be allowed. On Enterprise, an admin enables **Allow Local Plugin Imports**.

Once it is published, install it from **Cursor Settings → Plugins** by searching for **Trailblaze Scout**, or by running `/add-plugin trailblaze-scout` in chat.

Sign-in uses your Trailblaze account (OAuth). No API keys are required.
